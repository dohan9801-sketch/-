# 엑셀 업무 자동화 포트폴리오

크몽 등에 올릴 포트폴리오용 예제 모음입니다. 모든 데이터는 시연용 가짜 데이터입니다.

| 폴더 | 내용 | 크몽 카테고리 |
|---|---|---|
| [01_excel_to_web](01_excel_to_web/) | 엑셀 상품 목록 → 쇼핑몰 관리자 페이지 자동 등록 | 업무 자동화 |
| [02_excel_report](02_excel_report/) | 지점별 엑셀 6개 → 월간 보고서 자동 작성 | 엑셀·스프레드시트 |

## 처음 한 번만: 설치

1. 파이썬을 설치합니다: https://www.python.org/downloads/
   - 설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요.
2. 이 폴더의 `setup.bat`을 더블클릭합니다.

그다음부터는 각 폴더의 `run.bat`을 더블클릭하면 실행됩니다.

## 폴더 구성

```
setup.bat              처음 한 번 실행 (필요한 프로그램 설치)
requirements.txt       설치할 파이썬 패키지 목록
01_excel_to_web/       포트폴리오 1: 엑셀 → 웹 자동 입력
02_excel_report/       포트폴리오 2: 엑셀 취합 → 보고서
```
