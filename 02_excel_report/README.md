# 포트폴리오 2: 지점별 엑셀 취합 → 월간 보고서 자동 작성

지점마다 따로 보내온 판매 엑셀 6개를 **버튼 한 번으로 합쳐서**, 표와 차트가 들어간 월간 보고서를 만듭니다.

- 수작업: 파일 열기 → 복사·붙여넣기 → 피벗·차트 → 서식 정리 약 1~2시간
- 자동화: 약 3초

## 실행 방법

1. (처음 한 번) 상위 폴더의 `setup.bat` 실행
2. 지점 파일을 `input` 폴더에 넣습니다. (지금은 시연용 6개가 들어 있음)
3. `run.bat` 더블클릭 → `output/월간보고서_2026-09.xlsx` 생성

지점 이름은 파일 이름의 `_` 앞부분에서 가져옵니다. (예: `강남점_2026년09월.xlsx` → 강남점)

## 만들어지는 보고서

| 시트 | 내용 |
|---|---|
| 요약 | 총매출·판매수량·지점 수·1위 지점, 지점별 순위표, 분류별 매출, 막대·원 차트 |
| 지점x분류 | 지점별 × 분류별 매출 표 |
| 일별추이 | 날짜별·지점별 매출과 일별 총매출 꺾은선 차트 |
| 상품순위 | 상품별 매출 순위와 비중 |
| 전체데이터 | 6개 지점의 모든 판매 내역을 한 표로 (필터 적용) |

## 현장 데이터처럼 지저분해도 처리합니다

시연용 파일은 일부러 모양을 조금씩 다르게 만들었습니다.

- **부산점**: 맨 위에 제목 줄이 있음 → 머리글(`날짜`, `금액`) 줄을 자동으로 찾음
- **대구점**: 열 순서가 다름 → 열 이름으로 찾아서 읽음
- **광주점**: 중간에 빈 줄이 있음 → 건너뜀
- 엑셀이 열려 있을 때 생기는 `~$` 임시 파일은 무시
- 읽을 수 없는 줄은 건너뛰고 어떤 파일 몇 행인지 알려 줌

## 파일 설명

| 파일 | 설명 |
|---|---|
| `merge_report.py` | 취합·보고서 생성 프로그램 |
| `input/` | 지점별 판매 엑셀 (시연용 6개) |
| `output/월간보고서_2026-09.xlsx` | 실행 결과 예시 |
| `make_sample_data.py` / `demo_reset.bat` | 시연용 지점 파일을 다시 만듦 |

## 포트폴리오 녹화 팁

1. `input` 폴더의 지점 파일 2~3개를 열어 "모양이 제각각인 파일"을 보여 줍니다. (부산점·대구점이 좋음)
2. `run.bat` 실행 화면을 녹화합니다.
3. 결과 보고서의 **요약** 시트(차트 포함)를 크게 캡처합니다. 이 캡처가 대표 이미지로 가장 좋습니다.

## 실제 의뢰에 쓸 때 바꿀 곳

- `REQUIRED`의 열 이름을 의뢰인 엑셀에 맞게 바꿉니다. (예: `금액` → `매출액`)
- 보고서에 들어갈 항목은 `build_report()`에서 추가·삭제합니다.
