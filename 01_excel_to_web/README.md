# 포트폴리오 1: 엑셀 → 웹사이트 자동 입력

엑셀에 정리한 상품 목록을 쇼핑몰 관리자 페이지에 **한 건씩 자동으로 입력·등록**하고,
건별 처리 결과(완료/실패 사유)를 엑셀로 돌려줍니다.

- 수작업: 상품 1건당 약 1분 → 100건이면 1시간 40분
- 자동화: 100건 약 1~2분, 실패 건은 사유와 함께 빨간색 표시

## 실행 방법

1. (처음 한 번) 상위 폴더의 `setup.bat` 실행
2. `run.bat` 더블클릭
   - 브라우저가 열리고, 로그인 → 상품 입력 → 등록이 자동으로 진행됩니다.
   - 끝나면 `output/처리결과_날짜_시간.xlsx`가 생깁니다.

브라우저는 PC에 설치된 **크롬 → 엣지** 순서로 찾아서 씁니다. 윈도우에는 엣지가 기본으로 있어서 따로 설치할 필요가 없습니다.

빠르게 실행하려면 명령 프롬프트에서:

```
python auto_input.py --fast          # 입력 속도를 늦추지 않음
python auto_input.py --headless      # 브라우저 창 없이 실행
python auto_input.py --excel 내파일.xlsx
```

## 파일 설명

| 파일 | 설명 |
|---|---|
| `auto_input.py` | 자동 입력 프로그램 |
| `demo_site/index.html` | 시연용 쇼핑몰 관리자 페이지 (계정: admin / 1234) |
| `data/상품목록.xlsx` | 입력할 상품 목록 (12건, 그중 2건은 일부러 틀린 값) |
| `output/처리결과_예시.xlsx` | 실행 결과 예시 (완료는 초록, 실패는 빨강) |
| `make_sample_data.py` / `demo_reset.bat` | 상품목록.xlsx를 처음 상태로 다시 만듦 |

## 포트폴리오 녹화 팁

1. `demo_site/index.html`을 더블클릭해서 관리자 페이지를 먼저 보여 줍니다. (수작업이면 이걸 하나씩 입력해야 한다는 걸 보여 주기)
2. `data/상품목록.xlsx`를 열어 입력할 데이터를 보여 줍니다.
3. `run.bat` 실행 → 자동으로 입력되는 화면을 녹화합니다. (윈도우 `Win + Alt + R` 또는 ShareX로 GIF 녹화)
4. `output/처리결과_*.xlsx`를 열어 완료·실패 표시를 보여 줍니다.

## 실제 의뢰에 쓸 때 바꿀 곳

- `auto_input.py`의 `login()`과 `register()` 안에 있는 `#name`, `#price` 같은 **입력칸 이름(선택자)**을 의뢰인 사이트에 맞게 바꿉니다.
  - 크롬에서 입력칸을 마우스 오른쪽 클릭 → **검사**하면 확인할 수 있습니다.
- `COLUMNS`에서 엑셀 열 이름을 의뢰인 엑셀에 맞게 바꿉니다.
- 로그인 정보는 코드에 직접 쓰지 말고 의뢰인이 실행할 때 입력하게 하는 것이 안전합니다.
- 캡차(자동입력 방지), 보안 프로그램이 있는 사이트는 자동화가 어렵거나 이용약관상 금지일 수 있으니 미리 확인하세요.
